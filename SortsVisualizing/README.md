# Визуализация алгоритмов сортировки

Данный проект представляет собой интерактивное приложение для наглядной демонстрации работы шести алгоритмов сортировки. Каждый алгоритм визуализируется в виде столбчатой диаграммы, где высота столбца соответствует значению элемента, а цвет отражает его текущее состояние (сравниваемый, перемещаемый, отсортированный). Анимация сопровождается звуковыми сигналами, что делает процесс более понятным и увлекательным.

## Возможности

- Выбор одного из шести алгоритмов:
  - Пузырьковая сортировка (Bubble Sort)
  - Сортировка вставками (Insertion Sort)
  - Сортировка выбором (Selection Sort)
  - Шейкерная сортировка (Cocktail Shaker Sort)
  - Гномья сортировка (Gnome Sort)
  - Быстрая сортировка (Quick Sort)
- Регулировка количества элементов массива (от 10 до 100).
- Настройка скорости анимации (задержка между шагами от 10 до 500 мс).
- Подсветка столбцов:
  - **красный** – сравниваемые элементы;
  - **жёлтый/оранжевый** – вставляемый или опорный элемент;
  - **зелёный** – уже отсортированные элементы.
- Звуковое сопровождение (для Windows) – разные тоны для сравнений и обменов.
- Завершение всех дочерних процессов при закрытии приложения.

## Технологии

- **Python 3.11+**
- **Tkinter** – графический интерфейс (главное окно)
- **Matplotlib** – построение и анимация столбчатых диаграмм
- **NumPy** – работа с массивами
- **winsound** – звуковые сигналы (Windows)
- **subprocess** – запуск отдельных модулей сортировок

## Установка и запуск

1. Убедитесь, что у вас установлен Python 3.11 или новее.
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-username/sorting-visualizer.git
   cd sorting-visualizer
3. Установите необходимые библиотеки:
    pip install matplotlib numpy
4. Запустите главный файл:
    python main.py

## Управление

После запуска откроется главное окно:
- Задайте количество элементов (по умолчанию 30).
- Задайте задержку между шагами в миллисекундах (по умолчанию 30).
- Нажмите на кнопку с названием нужной сортировки.
- Откроется новое окно с анимацией процесса. В заголовке отображается текущая информация (номер прохода, сравнения и т.д.).
- После завершения сортировки окно автоматически закроется. При желании вы можете закрыть его вручную – приложение корректно завершит процесс.
